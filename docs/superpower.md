# superpower.md — Kekuatan Proyek Ini

## Kesederhanaan
- Zero dependency: tidak ada npm, tidak ada build tool, tidak ada server.
- Buka `index.html` di browser — langsung jalan.

## Konversi via WhatsApp
- Tombol CTA langsung ke WhatsApp = zero friction untuk pengunjung.
- Pesan sudah terisi otomatis = pengunjung tidak perlu mengetik apa-apa.

## Mudah Dikelola
- Data buku di `books.json` — update buku tanpa sentuh kode.
- Tambah cover baru cukup taruh gambar di `assets/images/`.

## Cepat
- Static site = load instan, tidak ada API call, tidak ada database query.
- Bisa di-host gratis di GitHub Pages, Netlify, atau Vercel.
